## งานฝั่ง ERP ที่ต้องทำต่อ (C7, C8)

1. สำรองแล้ว: `ruka-erp/backups/ruka_catalog-before-phaseC-20261116-214444.json` (49 แถว)
2. เขียนข้อมูล 21 แถว (เฉพาะสินค้าที่ `web:true` อยู่แล้ว ไม่เปิดสินค้าที่ซ่อน)
   - GG-001 `nameEn` = Wearable portable fan, GG-002 `nameEn` = Portable fan
   - ตัดช่องว่างหัวท้ายใน name/note ของ GG-001, GG-002, TBL-005, TBL-007
   - ติด `useCases` ตามรายการในใบสั่งงาน
3. deploy `api/public-products.js` (เพิ่มฟิลด์ `useCases` + ตัดช่องว่าง) ขึ้น ruka-erp production
4. ข้อควรระวัง: ถ้ามีคนเปิดหน้า ERP ค้างไว้ก่อนเขียนข้อมูล แล้วกดบันทึกสินค้าตัวนั้น ข้อมูลเก่าจะทับแท็ก ให้รีเฟรช ERP หลังเขียน
